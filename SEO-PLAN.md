# Launch SEO plan

## Primary cluster

**Home appliance electricity costs / everyday home energy**

### Article 1
Primary keyword: **how much does it cost to run a fan overnight**
Secondary: fan electricity cost overnight, cost to run a fan for 8 hours, 75 watt fan cost, fan running cost per night.

Intent: informational / calculation.

### Article 2
Primary keyword: **how much electricity does a slow cooker use for 8 hours**
Secondary: slow cooker electricity cost, 200 watt slow cooker cost, crock pot electricity use, slow cooker running cost.

Intent: informational / calculation.

### Article 3
Primary keyword: **how much does it cost to run an air purifier 24/7**
Secondary: air purifier electricity cost, 50 watt air purifier cost, air purifier running cost per month, air purifier power consumption.

Intent: informational / calculation.

## SERP observations

The initial live SERP review found that these topics already have competing pages, so they should NOT be treated as guaranteed zero-competition keywords. The opportunity is to build a tighter topical cluster, use primary sources, clearly separate assumptions from measured consumption, and answer the exact long-tail question immediately.

## Recommended next pages

Do not publish all at once merely for volume. After Search Console data arrives, expand only where impressions and query variations justify it.

Potential next cluster pages:
- how much does it cost to run a 20 inch box fan
- how much does a 50 watt fan cost to run 24 hours
- how much electricity does a crock pot use on low
- how much does a 100 watt air purifier cost per month
- appliance electricity cost calculator

## Internal linking

Homepage -> Guides hub -> each article.

Each article links to both other articles. The homepage calculator supports the entire cluster.

## Technical

Static HTML, minimal JS, one CSS file, no framework, no external fonts, no image requests, HTTPS through Vercel, canonical URLs, robots.txt, XML sitemap, 404 page, structured data.
